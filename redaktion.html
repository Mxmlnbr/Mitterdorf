Direkt auf GitHub speichern

Einmal einrichten, danach genügt ein Klick auf „Veröffentlichen“ – kein Herunterladen und Hochladen mehr.
So legst du den Schlüssel an: Auf github.com unter Settings → Developer settings → Personal access tokens → Fine-grained tokens einen neuen Schlüssel erzeugen. Bei Repository access nur dieses eine Repository auswählen, bei Permissions ausschließlich Contents: Read and write vergeben und eine Laufzeit setzen.
Wichtig zur Sicherheit: Der Schlüssel bleibt in diesem Browser auf diesem Gerät und wird nie ins Repository geschrieben. Wer Zugriff auf dein entsperrtes Gerät hat, kann damit aber Änderungen veröffentlichen. Nutze ihn deshalb nicht an fremden oder geteilten Rechnern. Ist er abhandengekommen, lässt er sich auf github.com sofort widerrufen – ein neuer ist in zwei Minuten erstellt.
Ablauf ohne GitHub-Zugang: Änderungen hier eintragen, unten daten.json herunterladen, die Datei im GitHub-Repository per Drag-and-drop ersetzen und den Commit bestätigen. Nach etwa einer Minute ist die App aktuell. Diese Seite speichert nichts von selbst – alles bleibt im Browser, bis du die Datei herunterlädst.
